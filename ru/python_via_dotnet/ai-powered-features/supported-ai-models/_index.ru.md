Aspose.Words теперь использует расширенные модели AI для улучшения обработки и анализа документов. Благодаря пространству имен Aspose.Words.AI разработчики могут получить доступ к функциям, которые используют AI для таких задач, как обобщение и анализ документов, интегрируя модели порождающего языка от лидеров отрасли.

Aspose.Words в настоящее время библиотека поддерживает интеграцию с семействами моделей OpenAI, Google и Claude. Эти модели предоставляют мощные возможности для работы с документами. Благодаря бесперебойному взаимодействию с этими инструментами AI, Aspose.Words упрощаются сложные задачи и повышается производительность разработчиков.

Вы можете создать экземпляр модели, используя метод [create](https://reference.aspose.com/words/python-net/aspose.words.ai/aimodel/create/) класса [AiModel](https://reference.aspose.com/words/python-net/aspose.words.ai/aimodel/). Полный список поддерживаемых типов моделей приведен в перечислении [AiModelType](https://reference.aspose.com/words/python-net/aspose.words.ai/aimodeltype/).

В следующем примере кода показано, как создать новый экземпляр класса **AiModel**.

{{< highlight python >}}
def create(self, model_type: aspose.words.ai.AiModelType):
    ...
{{< /highlight >}}
