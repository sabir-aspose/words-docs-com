Aspose.WordsのためのJava 一般的な文書処理タスクを簡素化する**Aspose.Words LowCode API**を提供します。 このAPIは、ドキュメント比較、コンテンツ抽出、画像変換、テキスト置換などの高レベルの操作を最小限の労力で実行したい開発者向けに設計されてい

LowCodeAPIは、きめ細かい制御よりも迅速な実装が重要なシナリオに最適です。 のLowCode機能を詳しく見てみましょう Aspose.WordsのためのJava.

{{% alert color="primary" %}}

LowCodeAPIでは文書構造を変更できないことに注意することが重要です。

{{% /alert %}}

## LowCodeAPIで利用可能な機能

`Aspose.Words LowCode API`は現在サポートしています:

* ある形式から別の形式への**Converting**ドキュメント–[Converter](https://reference.aspose.com/words/java/com.aspose.words/converter/)クラス
* **Comparing**ドキュメント–[Comparer](https://reference.aspose.com/words/java/com.aspose.words/comparer/)クラス
* **Mail merging**-[MailMerger](https://reference.aspose.com/words/java/com.aspose.words/mailmerger/)クラス
* LINQ構文に基づく**Reporting**–[ReportBuilder](https://reference.aspose.com/words/java/com.aspose.words/reportbuilder/)クラス
* **Merging**ドキュメント–[Merger](https://reference.aspose.com/words/java/com.aspose.words/merger/)クラス
* **Search and replace**-[Replacer](https://reference.aspose.com/words/java/com.aspose.words/replacer/)クラス
* ドキュメントの**Digital signing**–[DigitalSignature](https://reference.aspose.com/words/java/com.aspose.words/digitalsignature/)クラス
* **Splitting**異なる基準を使用した部品への文書–[Splitter](https://reference.aspose.com/words/java/com.aspose.words/splitter/)クラス
* **watermark**–[Watermarker](https://reference.aspose.com/words/java/com.aspose.words/watermarker/)クラスの追加

{{% alert color="primary" %}}

Low Code以外の各関数の詳細な説明は、開発者ガイドのセクションにあります。

{{% /alert %}}

## 流暢なものと非流暢なものAPI

Aspose.WordsのためのJava 流暢なAPIsと非流暢なAPIsの両方をサポートし、開発者はコーディングの好みやプロジェクトのニーズに最も適したスタイルを選択できます。 いくつかの例を見て、これら2つのタイプのAPIがどのように異なるかを見てみましょう。

{{% alert color="primary" %}}

FluentAPIでは、操作はコンテキスト(ComparerContextやReplacerContextなど)を介して構成および実行できます。 このコンテキストには、一般的なオプションが含まれます。 これにより、関連するすべてのメソッドが一貫した構成で動作することが保証され、APIは強力で複雑なシナリオで管理が容易になります。

{{% /alert %}}

## なぜAspose.WordsLow Codeを使うのか

**Aspose.Words LowCode API**は、クリーンで読みやすい構文で高レベルの文書処理タスクを迅速に実装するのに役立ちます。 これは、Wordドキュメントを操作するときに速度、シンプルさ、保守可能なコードを必要とする開発者にとって特に便利です。

より高度なオプションを探索するには、LowCodeAPIsと完全なAspose.Wordsオブジェクトモデルをいつでも組み合わせることができます。 [API documentation](https://reference.aspose.com/words/java/com.aspose.words/)のより多くのLow Codeの例を参照してください。
