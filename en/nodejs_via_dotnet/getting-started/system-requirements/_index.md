Aspose.Words for Node.js via .NET does not require any third party product such as Microsoft Word to be installed. Aspose.Words itself is an engine for creating, modifying, converting, and rendering of documents in various formats, including Microsoft Word document formats.

## Supported Operating Systems

Aspose.Words for Node.js via .NET supports Microsoft Windows® x64 platform and Node.js 14.17.0 or higher.
