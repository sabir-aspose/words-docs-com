Aspose.Words Pro Java poskytuje **Aspose.Words LowCode API**, což zjednodušuje běžné úlohy zpracování dokumentů. Tento API je určen pro vývojáře, kteří chtějí provádět operace na vysoké úrovni, jako je porovnávání dokumentů, extrakce obsahu, konverze obrázků a nahrazení textu s minimálním úsilím.

LowCode API je ideální pro scénáře, kde je rychlá implementace důležitější než jemnozrnná kontrola. Podívejme se blíže na schopnosti LowCode Aspose.Words pro Java.

{{% alert color="primary" %}}

Je důležité si uvědomit, že LowCode API neumožňuje změnit strukturu dokumentu.

{{% /alert %}}

## Dostupné funkce v LowCode API

`Aspose.Words LowCode API` v současné době podporuje:

* **Converting** dokumenty z jednoho formátu do druhého – třída [Converter](https://reference.aspose.com/words/java/com.aspose.words/converter/)
* **Comparing** dokumenty-třída [Comparer](https://reference.aspose.com/words/java/com.aspose.words/comparer/)
* **Mail merging** – třída [MailMerger](https://reference.aspose.com/words/java/com.aspose.words/mailmerger/)
* **Reporting** na základě syntaxe LINQ - třída [ReportBuilder](https://reference.aspose.com/words/java/com.aspose.words/reportbuilder/)
* **Merging** dokumenty-třída [Merger](https://reference.aspose.com/words/java/com.aspose.words/merger/)
* **Search and replace** – třída [Replacer](https://reference.aspose.com/words/java/com.aspose.words/replacer/)
* **Digital signing** dokumentů-třída [DigitalSignature](https://reference.aspose.com/words/java/com.aspose.words/digitalsignature/)
* **Splitting** dokument do částí podle různých kritérií-třída [Splitter](https://reference.aspose.com/words/java/com.aspose.words/splitter/)
* Přidání **watermark** – třída [Watermarker](https://reference.aspose.com/words/java/com.aspose.words/watermarker/)

{{% alert color="primary" %}}

Vezměte prosím na vědomí, že podrobný popis každé funkce mimo Low Code najdete v sekci Průvodce pro vývojáře.

{{% /alert %}}

## Plynule a plynule API

Aspose.Words pro Java podporuje Fluent i non-Fluent APIs, což vývojářům umožňuje zvolit styl, který nejlépe vyhovuje jejich preferencím kódování a potřebám projektu. Podívejme se na několik příkladů, abychom zjistili, jak se tyto dva typy API liší.

{{% alert color="primary" %}}

V aplikaci Fluent API lze operace konfigurovat a provádět prostřednictvím kontextu (například ComparerContext nebo ReplacerContext). Tento kontext obsahuje běžné možnosti. Zajišťuje, že všechny související metody pracují s konzistentní konfigurací, díky čemuž je API výkonný a snadno ovladatelný ve složitých scénářích.

{{% /alert %}}

## Proč Používat Aspose.Words Low Code

**Aspose.Words LowCode API** vám pomůže rychle implementovat úkoly zpracování dokumentů na vysoké úrovni s čistou a čitelnou syntaxí. Je zvláště užitečný pro vývojáře, kteří potřebují rychlost, jednoduchost a udržovatelný kód při práci s dokumenty Word.

Chcete-li prozkoumat pokročilejší možnosti, můžete vždy kombinovat LowCode APIs s úplným objektovým modelem Aspose.Words. Podívejte se na další příklady Low Code v [API documentation](https://reference.aspose.com/words/java/com.aspose.words/).
