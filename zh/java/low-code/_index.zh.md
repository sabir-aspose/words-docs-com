Aspose.Words为Java 提供**Aspose.Words LowCode API**，它简化了常见的文档处理任务。 此API专为希望以最小的努力完成文档比较，内容提取，图像转换和文本替换等高级操作的开发人员而设计。

LowCodeAPI非常适合快速实现比细粒度控制更重要的场景。 让我们仔细看看LowCode功能 Aspose.Words为Java.

{{% alert color="primary" %}}

需要注意的是，LowCodeAPI不允许您更改文档结构。

{{% /alert %}}

## LowCodeAPI中的可用特性

`Aspose.Words LowCode API`目前支持:

* **Converting**从一种格式到另一种格式的文档-[Converter](https://reference.aspose.com/words/java/com.aspose.words/converter/)类
* **Comparing**文档-[Comparer](https://reference.aspose.com/words/java/com.aspose.words/comparer/)类
* **Mail merging**-[MailMerger](https://reference.aspose.com/words/java/com.aspose.words/mailmerger/)类
* **Reporting**基于LINQ语法-[ReportBuilder](https://reference.aspose.com/words/java/com.aspose.words/reportbuilder/)类
* **Merging**文档-[Merger](https://reference.aspose.com/words/java/com.aspose.words/merger/)类
* **Search and replace**-[Replacer](https://reference.aspose.com/words/java/com.aspose.words/replacer/)类
* **Digital signing**文档-[DigitalSignature](https://reference.aspose.com/words/java/com.aspose.words/digitalsignature/)类
* **Splitting**使用不同的条件将文档分成部分–[Splitter](https://reference.aspose.com/words/java/com.aspose.words/splitter/)类
* 添加**watermark**-[Watermarker](https://reference.aspose.com/words/java/com.aspose.words/watermarker/)类

{{% alert color="primary" %}}

请注意，可以在开发人员指南部分中找到Low Code之外的每个功能的详细描述。

{{% /alert %}}

## 流利和非流利API

Aspose.Words为Java 支持Fluent和Non-FluentAPIs，允许开发人员选择最适合其编码偏好和项目需求的样式。 让我们看看一些例子，看看这两种类型的API是如何不同的。

{{% alert color="primary" %}}

在FluentAPI中，可以通过上下文（如ComparerContext或ReplacerContext）配置和执行操作。 此上下文包含常用选项。 它确保所有相关方法以一致的配置运行，使API功能强大，易于在复杂场景中管理。

{{% /alert %}}

## 为什么使用Aspose.WordsLow Code

**Aspose.Words LowCode API**帮助您使用干净、可读的语法快速实现高级文档处理任务。 它对于在处理Word文档时需要速度，简单性和可维护代码的开发人员尤其有用。

要探索更高级的选项，您始终可以将LowCodeAPIs与完整的Aspose.Words对象模型结合使用。 在[API documentation](https://reference.aspose.com/words/java/com.aspose.words/)中查看更多Low Code示例。
