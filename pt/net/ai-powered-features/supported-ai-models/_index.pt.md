Aspose.Words agora utiliza modelos avançados AI para melhorar o processamento e a análise de documentos. Com o namespace Aspose.Words.AI, os desenvolvedores podem acessar recursos que utilizam AI para Tarefas como sumarização e análise de documentos, integrando modelos de linguagem generativa de líderes do setor.

Aspose.Words atualmente, a biblioteca oferece suporte à integração com as famílias de modelos OpenAI, Google e Claude. Esses modelos trazem recursos poderosos para trabalhar com documentos. Ao permitir uma interação perfeita com essas ferramentas AI, Aspose.Words simplifica tarefas complexas e aumenta a produtividade dos desenvolvedores.

Você pode criar uma instância de modelo usando o método [Create](https://reference.aspose.com/words/net/aspose.words.ai/aimodel/create/) da classe [AiModel](https://reference.aspose.com/words/net/aspose.words.ai/aimodel/). A lista completa dos tipos de modelo suportados está listada na enumeração [AiModelType](https://reference.aspose.com/words/net/aspose.words.ai/aimodeltype/).

O exemplo de código a seguir mostra como criar uma nova instância da classe **AiModel**.

{{< highlight csharp >}}
public static AiModel Create(AiModelType modelType)
{{< /highlight >}}
