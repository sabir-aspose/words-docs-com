Aspose.Words sekarang memanfaatkan model AI tingkat lanjut untuk meningkatkan pemrosesan dan analisis dokumen. Dengan namespace Aspose.Words.AI, pengembang dapat mengakses fitur yang menggunakan AI untuk tugas-tugas seperti ringkasan dan analisis dokumen, mengintegrasikan model bahasa generatif dari para pemimpin industri.

Pustaka Aspose.Words saat ini mendukung integrasi dengan keluarga model OpenAI, Google, dan Claude. Model-model ini menghadirkan kemampuan yang kuat untuk bekerja dengan dokumen. Dengan memungkinkan interaksi tanpa batas dengan alat AI ini, Aspose.Words menyederhanakan tugas kompleks dan meningkatkan produktivitas bagi pengembang.

Anda dapat membuat instance model menggunakan metode [Create](https://reference.aspose.com/words/net/aspose.words.ai/aimodel/create/) dari kelas [AiModel](https://reference.aspose.com/words/net/aspose.words.ai/aimodel/). Daftar lengkap tipe model yang didukung tercantum dalam enumerasi [AiModelType](https://reference.aspose.com/words/net/aspose.words.ai/aimodeltype/).

Contoh kode berikut menunjukkan cara membuat instance baru dari kelas **AiModel**.

{{< highlight csharp >}}
public static AiModel Create(AiModelType modelType)
{{< /highlight >}}
